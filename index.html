User List Query Builder

Upload a CSV of user IDs, pick the filters, and copy a Snowflake query that returns the matching user IDs. Everything runs in your browser; nothing is uploaded.

STEP 1

Input IDs

Drop one or more CSVs here. Row 1 of each must be the header. IDs from all files are combined into one list.

All files must hold the same type of ID.
Or paste IDs (added as another list)
STEP 2

Filters

Turn on a filter, then choose Include (keep only users who match) or Exclude (drop users who match). Filters combine with AND.
